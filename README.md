# Mangalib Ultimate Helper

Профессиональный инструмент для модераторов и пользователей сайтов семейства Lib: MangaLib, RanobeLib, HentaiLib, AnimeLib, SlashLib.

Активируется **только** для пользователей с ролью модератора или администратора — обычные пользователи не увидят никакого интерфейса.

---

## Возможности

- **🛡️ Модерация** — автозаполнение попапа бана, цветовая кодировка жалоб, шпаргалка правил, история банов, пакетное удаление комментариев
- **🤖 ИИ-анализ** — автоматическая проверка комментариев и тем форума на нарушение правил. Поддерживает DeepSeek, ChatGPT, Gemini, Claude, Groq и др. ИИ обучается на действиях модераторов и накапливает базу примеров
- **🔨 Полуавтоматический ИИ** — при вердикте «нарушает» кнопка «Применить» сразу выставляет причину в попапе бана
- **🔔 Webhook-уведомления** — при высокой уверенности ИИ автоматически отправляет уведомление о нарушении в Discord или Telegram
- **📊 Командная панель** — онлайн-статус модераторов, watchlist ключевых слов, объявления команды. Данные раздельны для каждого сайта (MangaLib / HentaiLib / и др.)
- **👤 Тултип пользователя** — при наведении на ник показывает уровень, роли, дату регистрации, активные баны. Поддерживает приватные заметки на пользователей
- **📖 Автоскролл** — плавный скролл при чтении манхвы с автопереходом на следующую главу
- **🎨 Персонализация** — пресеты тем, кастомный цвет акцента, обои, шрифт и межстрочный интервал для ранобе

3. Выбери скачанный zip-файл

> Firefox и Chrome используют **один и тот же zip** — отдельных сборок не нужно.

## Использование

После установки на сайтах семейства Lib (при наличии роли модератора) в правом верхнем углу появятся кнопки:

- **📊 Панель** — командная панель модераторов
- **⚙️** — настройки расширения

Все функции включаются и настраиваются через шестерёнку.

---

## Настройка ИИ-анализа

1. Открой ⚙️ → вкладка **«🤖 ИИ»**
2. Выбери провайдера (DeepSeek, ChatGPT, Gemini, Claude, Qwen, Grok, Mistral)
3. Вставь API-ключ от выбранного провайдера
4. Опционально: укажи Groq-ключ как бесплатный резервный провайдер
5. Опционально: укажи Discord или Telegram webhook для уведомлений о нарушениях

Ключи хранятся локально в браузере и отправляются только выбранным провайдерам.
